# 猎聘金融销售候选人 List 工具

这是一个仅保存设计与实施计划的私有仓库。目标是在用户已登录的猎聘网页中，辅助收集“当前岗位属于金融领域渠道、机构或同业销售”的候选人，并在人工复核后写入现有钉钉表格。

当前仓库不包含可运行程序，也不包含候选人数据、平台 Cookie、钉钉密钥或导出文件。

## 已确定的 v1 范围

- 仅支持猎聘；脉脉作为后续独立适配器，领英不纳入自动采集。
- 用户在 Chrome 中手动完成公司检索和翻页，扩展读取当前可见结果页。
- 每家公司依次搜索“渠道”“机构”“同业”，每页最多处理 30 人。
- 只收录最近一段在目标公司的在职候选人，严格使用岗位白名单和排除词。
- 仅匹配者进入详情补全队列；详情页由一个专用标签页串行处理，遇到验证码、登录失效或页面异常立即暂停。
- 人工复核后按公司同步到钉钉；API 不可用时以 TSV 一键复制粘贴兜底。
- 不采集联系方式，不解锁完整姓名，不读取或保存平台 Cookie，不调用猎聘私有接口，不绕过平台限制。

## 钉钉候选人表固定列

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校`

## 在生活电脑继续

1. 用具有该私有仓库权限的 GitHub 账号登录。
2. 克隆仓库：`git clone https://github.com/Recordarsxy/liepin-candidate-list-tool.git`
3. 在 Codex 中打开仓库目录。
4. 先阅读 [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md)、设计规格和实施计划。
5. 新建 `codex/liepin-v1` 分支，再按实施计划逐项开发；不要直接在 `main` 上实现。
