# 猎聘/脉脉候选人复制工具

这是一个供 Windows Chrome 使用的本地加载扩展。它在猎聘和脉脉的候选人缩略卡片上增加“复制候选人”按钮；点击后会把当前卡片中明确可见的信息复制成一行，可直接粘贴到钉钉表格。

不再需要本地助手、配对码、候选人待办池或钉钉应用凭据。

## 固定字段

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校｜本科入学时间｜渠道来源`

复制内容为单行、无表头的 11 列文本。缺失信息保持空白，不自动打开详情页，不读取 Cookie，不采集联系方式。

## 日常使用

1. 在猎聘或脉脉手动搜索候选人。
2. 点击缩略卡片上的“复制候选人”。
3. 按钮显示“已复制”后，切换到钉钉表格。
4. 选中目标行的第一列并粘贴，内容会横向填入 11 列。

点击扩展图标可以打开侧边栏并一键开启或关闭所有卡片按钮。如果按钮显示“暂时无法识别”，扩展不会改写剪贴板，通常表示网站页面结构需要更新。


## 安装

参见 [Windows 安装与重新加载](docs/install-windows.md)。

## 目录

- `extension/`：Chrome MV3 扩展。
- `tests/fixtures/`：匿名化页面夹具。
- `helper/`：旧版待办池助手源码，仅保留历史；当前扩展不构建、不启动也不连接它。

真实候选人数据、密钥、SQLite、日志和导出文件均不得提交到 Git。
