# 金融销售候选人共享人才库（V1）

本仓库当前保存 V1 的已批准设计和可执行实施计划；尚未实现应用程序。该表述仅为当前的历史基线，实施应以本文档链接的计划为准。

V1 建立一个共享的金融渠道、机构与同业销售人才库，并在同一候选人记录上支持两条工作流：

1. **人才 List 收集**：任何通过宽口径人才池规则的候选人均进入详情队列，并尽力补全钉钉主表所需九列。
2. **岗位推荐**：用户粘贴岗位需求聊天文本，系统生成待审批、可版本化的规则草案；启用后的岗位会在每次页面扫描时与候选人同时匹配，并展示最匹配的 1–3 个岗位。

## V1 范围和边界

- 支持猎聘与脉脉。LinkedIn 不属于 V1：其官方规则禁止自动化 LinkedIn 扩展，因此不会接入自动化采集。
- 用户自行在已登录的页面完成搜索、翻页和页面切换。工具只在用户触发后读取当前页面的可见 DOM；不自动搜索或自动翻页。
- 脉脉优先解析用户触发时的可见 DOM。无法解析时，用户可粘贴当前页面文本；缺失字段保持空白并被标记，绝不推断。
- 不采集联系方式；不点击联系按钮、不收藏候选人、不调用私有端点、不拦截请求、不读取 Cookie、不绕过验证码或访问限制。
- 本地数据库只保存结构化职业证据和完成工作流所需字段，不保存完整简历页面原文。
- 钉钉输出始终是无表头的九列 TSV，复制到剪贴板后由用户粘贴；V1 不使用钉钉 API。
