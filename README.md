# 猎聘/脉脉候选人复制工具

这是一个供 Windows Chrome 使用的本地加载扩展。它在猎聘和脉脉的候选人缩略卡片上增加“加入批量”按钮；连续选择多位候选人后，可以一次复制为多行并直接粘贴到钉钉表格。

不再需要本地助手、配对码、候选人待办池或钉钉应用凭据。

## 固定字段

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校｜本科入学时间｜渠道来源`

每位候选人是无表头的 11 列文本，多位候选人用换行分隔。缺失信息保持空白，不自动打开详情页，不读取 Cookie，不采集联系方式。

## 日常使用

1. 在猎聘或脉脉手动搜索候选人。
2. 依次点击目标缩略卡片上的“加入批量”。
3. 确认右下角批量栏的已选人数；误选可以再次点击卡片按钮取消，也可以点击“清空”。
4. 点击“复制全部”。复制成功后当前页面选择会自动清空，但多行内容仍保留在剪贴板中。
5. 在钉钉表格中选中目标区域第一行的第一列并粘贴，内容会填入多行、每行 11 列。

批量队列只存在于当前页面内存；刷新、跳转或关闭页面后自动清空，不保存候选人数据。

点击扩展图标可以打开侧边栏并一键开启或关闭所有卡片按钮。如果按钮显示“暂时无法识别”，该候选人不会进入批量队列，通常表示网站页面结构需要更新。脉脉入口和自动化测试已经具备，但仍需要在用户当前真实脉脉页面做一次 DOM 验收。

## 目录

- `extension/`：Chrome MV3 扩展。
- `tests/fixtures/`：匿名化页面夹具。
- `helper/`：旧版待办池助手源码，仅保留历史；当前扩展不构建、不启动也不连接它。

真实候选人数据、密钥、SQLite、日志和导出文件均不得提交到 Git。

## 脉脉手动验收

在脉脉候选人列表中，“加入批量”会紧贴显示在每个可见候选人行的“立即沟通”或“沟通”左侧。脉脉适配器会按可见文本识别这两个沟通入口，即使文字嵌套在普通元素中也可以识别；它只根据当前页面可见的候选人行语义读取信息，不会打开详情页、读取隐藏内容或访问 Cookie。

请由登录脉脉的用户手动完成首次验收：重新加载已解压扩展后刷新脉脉列表，确认每个可见候选人行都有一个“加入批量”，且其位于“立即沟通”或“沟通”左侧；选择两行，点击“复制全部”，并粘贴到空白区域确认得到两行、每行 11 列。不要让自动化工具接管浏览器或登录脉脉，因为这种接管会触发登录保护。
