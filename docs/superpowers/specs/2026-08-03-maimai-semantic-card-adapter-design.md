# 脉脉语义候选卡片适配设计

## 目标

在脉脉招聘“搜索”候选人缩略页中，为每一行候选人显示“加入批量”按钮。用户逐个选择后，继续沿用现有批量栏，一次复制为固定 11 列 TSV 并粘贴到钉钉。

本次只修正脉脉候选卡片发现、字段解析和按钮挂载；猎聘适配器、批量队列和剪贴板格式保持不变。

## 卡片发现

脉脉页面使用会变化的构建类名，因此不再依赖 `candidate-card`、`resume-card` 等假定类名。

适配器以可见且文字完全等于“立即沟通”或“沟通”的文字节点作为锚点，不限定其父元素必须是 `button`、`a` 或带 `role=button`。从文字节点向上合并文字仍完全等于该标签的连续祖先，得到最外层沟通控件；没有文字且不具备独立交互语义的装饰图标或徽标可以保留在控件内。若祖先包含电话、菜单等独立可点击的兄弟控件，则在该祖先之前停止，避免把整个操作区当成沟通控件。

第一次遇到可见文字不再等于沟通标签的祖先时，以现有候选语义判断边界：该祖先若同时包含可见年龄和 `期望：`，说明已经到达候选人行，接受当前完整沟通控件；若不包含候选语义，则说明遇到了“立即沟通 更多”等部分匹配中间容器，整条锚点作废。这个判断完全不依赖当前控件的标签或交互属性，因此普通 `div`、嵌套 `span` 和标准按钮行为一致。

候选祖先必须同时满足：

- 只包含一个“立即沟通”或“沟通”锚点；
- 可见文字包含年龄，如 `26岁`；
- 可见文字包含 `期望：` 或 `期望:`；
- 不包含另一个已识别候选行。

文字锚点通过 `TreeWalker` 遍历可见文本节点获得，不在每次页面变化时遍历所有 `div/span` 元素。返回结果按页面顺序去重。现有 `MutationObserver` 继续处理滚动或筛选后动态出现的新行。

## 按钮位置

“加入批量”作为普通流内按钮插入到最外层沟通控件左侧，不使用固定定位或最高层级。按钮层级为普通页面层级，因此不会覆盖脉脉沟通弹窗。“立即沟通”和“沟通”两种标签使用相同位置规则。

页面右下角的批量栏继续显示 `已选 N 人｜复制全部｜清空`。复制成功后立即清空当前页面选择，剪贴板内容保留供用户粘贴。

## 字段解析

解析器只读取候选行当前可见文字和图标，不访问详情页、网络响应、Cookie 或联系方式。无法可靠确认的字段写空字符串。

固定 11 列保持：

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校｜本科入学时间｜渠道来源`

规则如下：

- 姓名：取头像右侧的显示姓名；脱敏单姓继续按明确性别补为先生或女士。
- 性别：只识别头像附近明确的红色女标或蓝色男标。
- 年龄：从 `N岁` 中只保留数字。
- 目前地点：从年龄、经验、学历所在摘要行读取，并沿用市级规范化，去除区县。
- 期望地点：从 `期望：` 行读取第一个地点，并规范化到市。
- 目前公司和岗位：读取右侧经历时间线中第一条工作经历的公司与岗位；教育经历不得作为公司。
- 硕士、本科学校：只从明确标注 `硕士`、`本科` 的教育经历读取。
- 本科入学时间：从明确本科教育经历的开始年份提取四位数字。
- 渠道来源：固定为 `脉脉`。

## 失败处理与隐私

- 找到候选行但不能得到姓名时显示“暂时无法识别”，不加入队列。
- 单个字段缺失不影响其他字段复制，对应单元格保持空白。
- 解析和自动化测试使用由用户截图抽象出的匿名 DOM 夹具，不保存截图中的真实姓名、公司、学校或其他候选人信息。
- 不通过浏览器自动化接管脉脉页面做验收，避免触发平台登录保护；安装后由用户手动刷新、选择测试候选人并粘贴验证结构。

## 测试与验收

- 匿名夹具包含三行候选人、由嵌套 `div/span` 构成的“立即沟通”和“沟通”锚点、沟通控件内的装饰图标、操作区内的独立电话控件、年龄、期望、工作和教育时间线。
- 验证每行只出现一个“加入批量”，按钮位于对应最外层沟通控件之前，且不会插入控件内部。
- 验证装饰图标不会截断沟通控件，但独立电话或菜单控件会阻止锚点继续扩展到整个操作区。
- 验证普通 `div` 沟通控件可在候选人行边界被接受，而“立即沟通 更多”等非候选中间容器会使锚点作废。
- 验证隐藏的“立即沟通”或“沟通”文字节点不会生成候选行或按钮。
- 验证动态新增候选行自动出现按钮，重复扫描不重复插入。
- 验证年龄、城市、公司、岗位、学校和本科开始年份映射；缺失字段为空。
- 验证选择两人后一次复制两行，每行恰好 11 列，来源为 `脉脉`，成功后选择清空。
- 运行扩展全量测试、类型检查和构建，再覆盖本机与桌面插件目录并校验文件哈希。
