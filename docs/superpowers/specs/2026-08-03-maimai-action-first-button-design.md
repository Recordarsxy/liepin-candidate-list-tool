# 脉脉“沟通按钮优先”采集设计

## 目标

脉脉列表页只要出现可见且文字完整为“立即沟通”或“沟通”的控件，就在其左侧显示“加入批量”。按钮显示不得依赖年龄、期望、学历、地点或时间线是否能被解析。

## 设计

- 扫描器以可见沟通文字为唯一按钮锚点，找到锚点后立即返回其动作容器用于挂载按钮。
- 点击按钮时，再从动作容器向上查找最近的、包含可靠候选人姓名的祖先节点作为候选卡片。
- 姓名解析排除“沟通/立即沟通”等动作文字；找到姓名后，其余 11 列按现有规则尽力解析，无法确认的字段写空字符串。
- 保留批量选择、11 列 TSV、复制成功后自动清空、总开关及猎聘逻辑。
- 仍忽略隐藏文字；完整动作文字之外的普通页面文字不生成按钮。

## 验收

- 没有年龄、期望、学历和时间线的匿名脉脉行，只要有姓名与“立即沟通”，仍显示一个“加入批量”按钮。
- 点击该按钮不会显示“暂时无法识别”；姓名被加入，其他缺失列为空。
- 原有脉脉与猎聘测试、类型检查和生产构建全部通过。
