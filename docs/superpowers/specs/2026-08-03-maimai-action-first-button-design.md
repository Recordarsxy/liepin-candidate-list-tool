# 脉脉“沟通按钮优先”采集设计

## 目标

脉脉列表页只要出现可见且文字完整为“立即沟通”或“沟通”的控件，就在其左侧显示“加入批量”。按钮显示不得依赖年龄、期望、学历、地点或时间线是否能被解析。

## 设计

- 扫描器以可见沟通文字为唯一按钮锚点，不限制锚点必须是 `button`、`div` 或带 ARIA role 的元素；每个锚点各自挂载一个按钮，共享父容器时也不合并。
- 点击按钮时，从动作锚点向上查找包含可靠姓名的完整候选人行，并选择年龄、经验、学历、期望和时间线证据得分最高的安全祖先；到达包含多个沟通动作的共享容器或 `body/html` 时停止，禁止借用另一行姓名。
- 性别优先采用姓名中明确的“先生/女士”，否则读取头像区域可见 SVG 的 `fill`、`stroke`、文字色或背景色（包括 CSS 计算样式），红色为女、蓝色为男。
- 工作和教育时间线扫描所有可见元素，不限定为 `div`；日期可位于一个文本节点，也可拆成“开始日期 / 连字符 / 结束日期”三个节点。每个时间线行按学历标签区分工作、硕士和本科。
- 同一时间段出现在嵌套内外层时，按包含关系选择信息得分最高、且在同分时最小的完整容器，避免只保留“日期 + 公司”而丢掉外层岗位，也避免只保留“日期 + 学校 + 专业”而丢掉学历标签。
- 学历标签统一归一化：`硕士`、`硕士研究生`、`研究生`、`MBA/EMBA/MPA/MPAcc` 归为硕士；`本科`、`本科统招`、`学士` 归为本科；博士和大专继续作为教育经历而不误判为工作。
- 姓名解析排除“沟通/立即沟通”等动作文字；找到姓名后，其余 11 列按现有规则尽力解析，无法确认的字段写空字符串。
- 保留批量选择、11 列 TSV、复制成功后自动清空、总开关及猎聘逻辑。
- 仍忽略隐藏文字；完整动作文字之外的普通页面文字不生成按钮。

## 验收

- 没有年龄、期望、学历和时间线的匿名脉脉行，只要有姓名与“立即沟通”，仍显示一个“加入批量”按钮。
- `span`、`p` 等普通元素中的完整沟通文字也能生成按钮；同一父容器的两个沟通锚点各生成一个按钮。
- 点击该按钮不会显示“暂时无法识别”；姓名被加入，其他缺失列为空。
- 当姓名与年龄、地点、期望和经历分属不同子容器时，点击后仍从整行读取这些字段，而不是只复制姓名。
- 红色头像角标、蓝色头像角标和“先生/女士”姓名后缀均能输出性别。
- `li` 等非 `div` 时间线及拆分日期仍能输出公司、岗位、硕士学校、本科学校和本科开始年份。
- 公司与岗位、学校与学历分属嵌套内外层时，仍能合并为一条完整经历。
- 原有脉脉与猎聘测试、类型检查和生产构建全部通过。
