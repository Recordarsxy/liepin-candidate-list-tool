# 候选人性别、姓名、年龄与地点规范化设计

## 目标

扩展复制猎聘缩略卡片时，读取姓名右侧明确显示的红色或蓝色性别 SVG，将性别写入固定 11 列中的第 3 列；当姓名只有一个姓氏并以星号脱敏时，根据已确认的性别补全为“先生”或“女士”；年龄列只输出数字，不包含“岁”；目前地点和期望地点只保留到市级，不包含区县。

复制流程、11 列顺序、总开关和缺失字段留空规则保持不变。

## 真实页面基线

2026-08-03 对当前猎聘缩略页做了只读检查，没有输出候选人姓名或年龄：

- 姓名后的女性图标是红色女性符号 SVG，标记色为 `#FF5833`。
- 姓名后的男性图标是蓝色男性符号 SVG，标记色为 `#085DFF`。
- 30 个可见姓名中，29 个是“单个汉字 + `**`”，其中 18 个带女性图标、11 个带男性图标；另有 1 个三字完整姓名。
- 30 个年龄标签全部是“数字 + `岁`”。
- 目前地点中，19 个已是市级名称，10 个是“市-区/县”，另有 1 个不含分隔符的四字市名。
- 30 个期望地点全部已是市级名称。
- 性别 SVG 本身没有可读取的文本、`title` 或 `aria-label`，因此猎聘适配器必须识别姓名容器中直接相邻的特定 SVG 标记；不能读取页面中其他红蓝图标。

## 方案选择

比较过三种方法：

1. **在猎聘页面适配器中识别姓名旁的性别 SVG（采用）**：范围明确，可同时验证图标位置和猎聘当前使用的标记色，不需要截图或图像识别。
2. 只读取元素的通用 CSS 颜色：实现简单，但可能把简历、状态等无关红蓝图标误判为性别。
3. 根据姓名或称谓推断性别：无法处理 `张**` 等脱敏姓名，也违反“不推断字段”的原则。

年龄采用严格的文本规范化，不从其他字段或出生年份推算。

地点采用层级分隔符规范化：保留市级第一段，不依赖城市名称长度，因此四字城市不会被截断。

## 字段规则

### 性别

- 只检查 `.new-resume-personal-name` 中姓名元素后直接相邻的性别图标 SVG。
- SVG 标记包含猎聘女性图标色 `#FF5833` 时返回 `女`。
- SVG 标记包含猎聘男性图标色 `#085DFF` 时返回 `男`。
- 两种标记都没有、同时出现或结构不符合预期时返回空字符串。
- 不扫描卡片中的其他 `.anticon`，避免把简历文件、阅读状态等图标误认为性别。

### 脱敏姓名

- 当原始姓名严格符合“一个汉字 + 一个或多个半角/全角星号”，并且性别为 `男` 时，输出“姓氏 + 先生”。
- 同一格式且性别为 `女` 时，输出“姓氏 + 女士”。
- 示例：`张**` + `男` → `张先生`；`李**` + `女` → `李女士`。
- 性别为空时保留原始脱敏姓名。
- 完整姓名、已经包含“先生/女士”的姓名、复姓或其他未确认格式全部保留原文，不截断、不猜测。

### 年龄

- `31岁` 输出 `31`。
- 已经只有数字的 `31` 仍输出 `31`。
- 接受数字与“岁”之间的普通空格，并去除首尾空白。
- 只接受 1–3 位十进制数字和可选的“岁”后缀。
- 年龄区间、生日、带其他单位或无法确认的格式输出空字符串，不从其他信息推算。
- 年龄规范化应用于猎聘和脉脉解析结果，保证复制列始终只包含数字。

### 目前地点和期望地点

- `上海-浦东新区` 输出 `上海`；`杭州/余杭区` 输出 `杭州`。
- 识别半角连字符 `-`、全角/长连字符 `－`、`—`、斜杠 `/` 和反斜杠 `\` 作为行政层级分隔符，并保留第一个非空片段。
- 没有层级分隔符的市级名称原样保留，包括 `呼和浩特` 等四字城市，不按字符数截断。
- 只有区、县、省或自治区而没有上级市信息时输出空字符串，不推断所属城市。
- 多个并列市级地点如果没有行政层级分隔符则保留原文，不把列表误当成区县层级。
- 同一规范化函数应用于 `current_location` 和 `preferred_location`，并同时覆盖猎聘和脉脉。

## 组件与数据流

1. 猎聘卡片解析器定位姓名容器并读取原始姓名。
2. 猎聘专用性别读取函数只检查姓名旁的 SVG，返回 `男`、`女`或空字符串。
3. 纯文本姓名规范化函数接收原始姓名和已确认性别，按上述规则返回最终显示姓名。
4. 纯文本年龄规范化函数接收页面可见年龄，返回数字字符串或空字符串。
5. 纯文本市级地点规范化函数分别处理目前地点和期望地点，返回市级文本或空字符串。
6. `CandidateDraft` 继续使用现有 `name`、`gender`、`age`、`current_location` 和 `preferred_location` 字段；剪贴板格式化器无需改变列顺序。

姓名、年龄和地点规范化函数不访问 DOM，便于单元测试。性别读取留在猎聘适配器内，因为它依赖猎聘特定的 SVG 结构。

## 错误处理

- 未识别性别不会阻止复制；性别列留空，脱敏姓名保留原文。
- 未识别年龄不会阻止复制；年龄列留空。
- 只有区县而无法确定所属市时不会阻止复制；对应地点列留空。
- 性别、年龄或地点解析失败不能改变其他不相关列。
- 页面结构变化时采取保守结果，不通过姓名、头像或其他视觉特征推断。

## 测试与验收

- 纯函数测试覆盖 `张** + 男`、`李** + 女`、性别缺失、完整姓名、已带称谓、全角星号和其他姓名格式。
- 年龄测试覆盖 `31岁`、`31`、带空格、空值、年龄区间和非年龄文本。
- 地点测试覆盖市级原文、“市-区”、“市/区”、四字城市、区县孤值、省级孤值和空值。
- 猎聘匿名 DOM 夹具加入红色女性 SVG、蓝色男性 SVG、缺失性别和卡片内无关红色文件图标。
- 解析器测试验证无关图标不会造成误判，并验证姓名、性别、年龄和两个地点字段的组合结果。
- 脉脉回归测试验证年龄和地点同样规范化，其他字段解析不变。
- 全量测试、类型检查和构建通过后覆盖两个已安装扩展目录。
- 用户重新加载扩展后，在猎聘测试卡片点击“复制候选人”，只检查剪贴板结构和目标五列：姓名称谓正确、性别为 `男/女`、年龄不含“岁”、两个地点不含区县，且整行仍为 11 列。

## 不在本次范围内

- 不根据姓名、头像、其他页面信息或统计概率推断性别；唯一依据是姓名旁明确的性别 SVG。
- 不补全真实名字，只把已显示的姓氏改写为礼貌称谓。
- 不处理未经验证的复姓脱敏格式。
- 不维护全国行政区划数据库，也不从孤立的区县名反查所属城市。
- 不改变字段顺序、按钮交互或钉钉粘贴方式。
