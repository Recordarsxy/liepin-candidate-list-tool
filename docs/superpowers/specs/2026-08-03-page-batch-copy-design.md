# 猎聘/脉脉当前页面批量复制设计

## 目标

用户可以在猎聘或脉脉的同一缩略页连续选择多位候选人，然后一次复制并粘贴到钉钉表格。剪贴板内容为多行 TSV：每位候选人占一行，每行固定 11 列；粘贴到钉钉第一列后形成“候选人数 × 11 列”的区域。

批量选择只存在于当前页面内存中，不写入 `chrome.storage`、磁盘或本地助手。刷新、跳转或关闭页面后自动消失。

## 已确认交互

- 每张可识别卡片显示“加入批量”按钮。
- 点击后把该候选人加入当前页队列，按钮变成“已选择”；再次点击会取消选择。
- 页面右下角显示批量栏：`已选 N 人｜复制全部｜清空`。
- 点击“复制全部”时，将所有候选人行按选择顺序用换行符连接，并一次写入剪贴板。
- 剪贴板写入成功后立即清空页面队列并把卡片按钮恢复为“加入批量”。剪贴板中的多行文本仍然保留，用户随后在钉钉粘贴即可。
- 扩展无法也不会监视用户何时在钉钉粘贴，因此“复制成功后清空”是已确认的等效流程。
- 写入剪贴板失败时保留全部选择，批量栏显示“重试”，避免候选人丢失。

## 方案选择

比较过三种方案：

1. **当前页面内存队列 + 批量栏（采用）**：不保存候选人数据，选择和取消清晰，复制失败可以重试。
2. 每次点击都重写整个剪贴板：少一次“复制全部”点击，但容易误覆盖剪贴板，且无法清楚地取消某一项。
3. 使用浏览器本地存储跨页保存：可以跨翻页，但会在磁盘暂存候选人信息；用户已确认不需要。

## 数据与去重

- 继续使用现有 `CandidateDraft` 和单行格式化函数，单行始终是无表头、10 个 Tab 的 11 列 TSV。
- 批量文本是按选择顺序排列的单行文本，用一个 `\n` 连接；不在结尾附加多余空行。
- 有平台候选人 ID 时，使用“平台 + ID”作为队列键。
- 没有平台 ID 时，使用完整 11 列行文本作为临时键。
- 同一候选人不能在当前队列中出现两次；再次点击是取消选择，不是新增重复行。
- 猎聘与脉脉在不同页面拥有独立队列，不跨标签页共享。

## 组件边界

1. 现有猎聘、脉脉解析器继续只负责把当前卡片解析为规范化的 `CandidateDraft`。
2. 现有单行格式化器继续负责 11 列顺序、来源列、字段清理和 Tab 分隔。
3. 新的当前页面批量控制器负责有序队列、去重键、加入/取消、生成多行文本、复制成功后清空。
4. 卡片按钮控制器负责注入按钮、按钮状态和动态卡片观察，并把选择事件交给批量控制器。
5. 批量栏只显示计数并提供“复制全部”和“清空”；它不解析卡片、不读浏览器存储。
6. 猎聘和脉脉内容脚本都创建同一种批量控制器，并注入 `navigator.clipboard.writeText`。

所有页面元素使用扩展专属 `data-candidate-collector-*` 属性，销毁采集器或关闭总开关时同时移除卡片按钮和批量栏。

## 错误处理

- 卡片无法识别时仍显示“暂时无法识别”，不加入空行。
- 单个候选人加入队列不访问剪贴板，因此不会因浏览器剪贴板权限影响选择。
- 队列为空时不显示批量栏，也不能发起空复制。
- 复制失败时不清空队列，错误信息放在“重试”按钮的 `title` 中。
- 手动点击“清空”立即恢复全部已选择按钮，并移除批量栏。
- 页面动态加载新卡片时继续插入“加入批量”，已有队列顺序不变。

## 脉脉支持范围

- 扩展清单已经匹配 `https://*.maimai.cn/*`，已有脉脉内容脚本、候选卡片解析器和匿名自动化测试。
- 批量控制器是双站点共享组件，因此批量交互同时用于猎聘和脉脉。
- 当前真实脉脉页面尚未做 DOM 现场验收；自动化测试通过后，仍需用户打开已登录的脉脉候选人缩略页进行一次现场卡片识别测试。
- 如果脉脉真实 DOM 与当前适配器不同，只修正脉脉选择器和字段映射，不改变批量队列接口。

## 测试与验收

- 纯队列测试覆盖选择顺序、重复阻止、再次点击取消、手动清空和多行 `\n` 拼接。
- UI 测试覆盖按钮初始/已选择状态、计数栏、复制成功后清空、复制失败保留、空队列隐藏和动态卡片加载。
- 回归测试验证每行恰好 11 列，多行数量等于选择人数，最后一列来源正确。
- 猎聘和脉脉内容脚本测试都选择两张匿名卡片，点击“复制全部”，验证一次剪贴板调用包含两行。
- 全量测试、类型检查和构建通过后覆盖两个已安装扩展目录，并比较 SHA256。
- 用户重新加载后，在猎聘选择多位候选人，复制并粘贴到测试表格，确认形成多行 11 列。
- 用户打开脉脉缩略页后，确认按钮出现并对至少一张测试卡片完成选择与复制；不输出真实候选人值。

## 不在本次范围内

- 不跨刷新、翻页、标签页或招聘平台保留队列。
- 不直接操作钉钉页面，也不检测粘贴事件。
- 不恢复本地助手、候选池、数据库、去重合并或钉钉 API。
- 不自动选择、批量扫描、翻页或打开候选人详情。
