# Windows 安装与重新加载

## 1. 构建扩展

在 PowerShell 中进入项目的 `extension` 目录并运行：

```powershell
npm.cmd ci
npm.cmd run build
```

## 2. 首次加载

打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式，选择“加载已解压的扩展程序”，然后选择项目的 `extension` 目录。

如果扩展已经加载，只需在扩展管理页找到“候选人复制工具”并点击重新加载按钮，不需要重新选择目录。

当前版本不需要运行本地助手、输入配对码或配置钉钉凭据。旧版助手文件可以保留，它们不会被当前扩展启动或访问。

## 3. 开启或关闭按钮

点击扩展图标打开侧边栏。按钮显示“采集已开启”时，猎聘和脉脉的候选人缩略卡片会出现“复制候选人”；点击该开关可以一键关闭或重新开启所有按钮。

## 4. 日常使用

1. 在猎聘或脉脉手动搜索候选人。
2. 在目标缩略卡片上点击“复制候选人”。
3. 等待按钮显示“已复制”。
4. 在钉钉表格中选中目标行的第一列并粘贴。

粘贴内容固定占用 11 列：

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校｜本科入学时间｜渠道来源`

无法识别或页面没有显示的信息会保持空白。如果按钮显示“暂时无法识别”，剪贴板不会改变，说明该卡片缺少最基本的信息或网站 DOM 已变化，需要更新页面适配器。
