# Windows 安装与重新加载

## 1. 构建扩展

在 PowerShell 中进入项目的 `extension` 目录并运行：

```powershell
npm.cmd ci
npm.cmd run build
```

## 2. 首次加载

打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式，选择“加载已解压的扩展程序”，然后选择项目的 `extension` 目录。

如果扩展已经加载，只需在扩展管理页找到“候选人复制工具”并点击重新加载按钮，不需要重新选择目录。

当前版本不需要运行本地助手、输入配对码或配置钉钉凭据。旧版助手文件可以保留，它们不会被当前扩展启动或访问。

## 3. 开启或关闭按钮

点击扩展图标打开侧边栏。按钮显示“采集已开启”时，猎聘和脉脉的候选人缩略卡片会出现“加入批量”；点击该开关可以一键关闭或重新开启所有按钮。

## 4. 日常使用

1. 在猎聘或脉脉手动搜索候选人。
2. 在每张目标缩略卡片上点击“加入批量”；再次点击可取消选择。
3. 在右下角批量栏确认已选人数，需要放弃时点击“清空”。
4. 点击“复制全部”。复制成功后页面选择自动清空。
5. 在钉钉表格中选中目标区域第一行的第一列并粘贴。

每位候选人固定占用 11 列，多位候选人会填入多行：

`目前公司｜姓名｜性别｜年龄｜目前地点｜期望地点｜目前岗位｜硕士学校｜本科学校｜本科入学时间｜渠道来源`

批量队列只保留在当前页面内存中，刷新、跳转或关闭页面后自动清空。无法识别或页面没有显示的信息会保持空白。如果按钮显示“暂时无法识别”，该卡片不会进入队列，说明它缺少最基本的信息或网站 DOM 已变化，需要更新页面适配器。

脉脉已经包含扩展入口和自动化解析测试，但首次使用仍应在当前真实脉脉缩略页确认按钮与实际候选卡片一一对应。
